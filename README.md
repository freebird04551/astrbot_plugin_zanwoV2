## 📦 插件简介

【仅QQ】QQ名片点赞插件。用户可订阅每日定时点赞，使用服务器本地时间和 `HH:MM` 格式，默认为 `00:00`。可在 控制面板>插件配置 设置自动点赞时间和群聊白名单；未配置白名单时所有群聊均可使用。

## ⌨️ 命令

|     命令      |      说明        |
|:-------------:|:------------------------------------:|
|     赞我 [数量]       | 给自己点赞，数量可省略，默认20  |
|     赞@XXX [数量]       | 给被@用户点赞，可同时@多人，默认20  |
|     自然语言点赞       | 使用唤醒词描述目标和数量，由大模型调用点赞工具  |
| /订阅点赞      | 加入每日定时点赞列表    |
| /取消订阅点赞   | 退出每日定时点赞列表 |
| /订阅点赞列表   | 查看当前订阅点赞的用户ID列表 |
| /谁赞了bot      | 管理员查看谁赞了bot，别名 `/谁赞了你` |

## 📌 注意事项

- 每位用户每天最多20个赞
- SnowLuma 的点赞接口不返回实际到账数量；插件显示的是接口接受的批量点赞数量，实际到账以QQ为准
- 多个 QQ 账号连接同一 AstrBot 时，每个已连接账号都会为订阅用户点赞

## ❓ 常见问题

### Q: 为什么点赞失败？

- 可能是因为用对方隐私设置未开启陌生人点赞权限，
- 或者已达到QQ点赞次数限制
- 或者是你没加bot好友，而bot今日给陌生人点赞量也已到达上限
